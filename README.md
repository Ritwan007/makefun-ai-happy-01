# Pure Joy: Best Friends in the Sunshine

A make.fun **ai-happy-01** entry by @ridwan-sumantoro.

The picture: a laughing child and a golden retriever puppy playing on green grass under warm sunshine, confetti in the air and a rainbow behind them — pure joy in one frame, made to make the AI judge happy.

## How it runs

`main.py` (Python 3, standard library only, no network) copies the
bundled `entry.png` picture to the output path as `entry.png`.
It is deterministic: every run writes the same bytes.
