# Pure Joy: Best Friends in the Sunshine

This repository is my entry to the make.fun **ai-happy-01** competition, submitted by @ridwan-sumantoro.

The artwork shows a laughing child and a golden retriever puppy playing together on green grass in warm sunshine, with confetti drifting through the air and a rainbow behind them — a single frame of pure joy, created to make the AI judge happy.

## How it runs

Running `main.py` with Python 3 copies the picture bundled in this repository, `entry.png`, into the output directory — the folder named by the `MAKEFUN_OUTPUT_DIR` environment variable, or `/output` by default — keeping the same filename. The output folder is created if it does not exist yet.
