# Pure Joy: Best Friends in the Sunshine

A make.fun ai-happy-01 entry by @ridwan-sumantoro.

The picture shows a laughing child and a golden retriever puppy playing together on green grass under warm sunshine, with confetti drifting through the air and a rainbow arching behind them — pure joy captured in a single frame, created to make the AI judge happy.

## How it runs

Running `main.py` copies the bundled `entry.png` picture to the output path. The output directory comes from the `MAKEFUN_OUTPUT_DIR` environment variable, falling back to `/output` when it is not set, and the directory is created automatically if it does not exist yet.

The program uses only the Python 3 standard library, makes no network calls, and is fully deterministic — every run delivers exactly the same bytes.
